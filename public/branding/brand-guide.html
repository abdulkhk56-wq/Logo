An operational co-pilot for oil and gas control rooms. The identity is built for the people who run the process: calm, exact and confident, with one point of heat.

The idea

Two flames, one boundary between them

  • Outer blade

    The process: energy, throughput, the flame of the plant. It wraps and protects everything inside it.

  • Inner blade

    The operator. A second, smaller tongue that leans the other way: SAFI and the crew working in tandem, neither one replacing the other.

  • S-channel

    A cut of constant width (4.6u) that separates the two. It is the filter path, where noise is taken out before it reaches the operator, and it draws the letter S.

  • Level base

    The flame stands on a flat, horizontal base: a setpoint, a stable operating level. No drop, no bulb, no flicker.

Exploration

Four constructions, scored on the same six criteria

Each concept uses a different visual construction: subtraction by bands, concentric offset, figure and ground in a container, and a single channel cut. Scores are 1 to 5.

App icon

Built to hold at 16 pixels

The symbol is one solid silhouette with a single cut, so it keeps its shape at favicon size. Below about 20px the channel closes and the silhouette carries the mark on its own. That is intended.

Inside the HMI

Control-room displays built to ISA-101 keep colour for abnormal conditions, and amber is commonly an alarm-priority colour. Inside operator screens, keep Flare to the logo and splash. Use Graphite, Steel and Petroleum for interface accents so the brand never looks like an alarm.

Usage

Clear space, minimum size, and what to avoid

Clear space

Keep a margin of one quarter of the symbol height on every side.

Minimum size

Lockup ≥ 96px wide (24mm print)
Symbol ≥ 16px (5mm print)

Below 96px, use the symbol alone. The wordmark is never set smaller than 12px cap height.

Proportions

Cap height = 0.54 × symbol height
Gap = 0.27 × symbol height
S-channel = 4.6 / 106 of symbol height

Always use the supplied files. Never retype the wordmark in a font.
